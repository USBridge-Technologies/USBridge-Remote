# Диагностика UDP видео через FRP

## Ручная проверка приёма UDP на клиенте

```bash
# 1. Запусти приложение, подключись через FRP, нажми «Запустить видео»
# 2. В логе найди порт, например: "UDP порт приёма: 64624"

# 3. Останови видео в приложении

# 4. В отдельном терминале — слушай UDP на этом порту:
nc -u -l 64624

# 5. Снова запусти видео в приложении (nc уже слушает — порт будет занят!)
#    Или: запусти nc ДО запуска видео, тогда приложение возьмёт другой порт.
#    Лучше: запусти приложение, запомни порт из лога, останови видео,
#    запусти nc -u -l ПОРТ, затем в приложении снова запусти видео.
#    Приложение переподключится с новым портом — тогда nc не поможет.

# Альтернатива: проверь, приходят ли пакеты на 127.0.0.1
# (запусти в отдельном терминале ДО запуска видео):
tcpdump -i lo0 -n udp port 64624 -c 50
# Замени 64624 на актуальный порт из лога приложения
```

## Проверка на USBridge (сервер)

```bash
# UDP на порт 55000 (FRP proxy) — видео модуль должен слать сюда
sudo tcpdump -i lo -n udp port 55000 -c 20
# Запусти видео в приложении — должны появиться пакеты
```

## Проверка GStreamer вручную

```bash
# Запусти приложение, запомни порт (например 64624), останови видео
# В терминале:
export GST_DEBUG=3
gst-launch-1.0 -v udpsrc port=64624 buffer-size=2097152 caps="application/x-rtp,media=video,encoding-name=H264,payload=96" ! \
  rtph264depay ! h264parse ! avdec_h264 ! autovideosink
# Запусти видео в приложении (приложение возьмёт другой порт)
# Или: сначала gst-launch, потом приложение — тогда приложение займёт другой порт
```

## Схема потока

```
[USBridge: FFmpeg RTP] → 127.0.0.1:55000 → [FRP video_sudp proxy] →
  QUIC туннель →
[Клиент: FRP visitor] → 127.0.0.1:ПОРТ → [GStreamer udpsrc RTP → rtph264depay]
```

## Чеклист

- [ ] На USBridge: `tcpdump -i lo udp port 55000` показывает пакеты при запуске видео
- [ ] FRP proxy `video_sudp` с `localPort: 55000` в конфиге
- [ ] FRP visitor на клиенте слушает 18555
- [ ] Bootstrap отправляет пакеты на 18555 до старта GStreamer
- [ ] В логе приложения: "Первый кадр получен" — если нет, UDP не доходит до GStreamer
